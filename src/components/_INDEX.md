# src/components 架构说明
React组件库
⚠️ 文件夹变化时请更新此文件

## 目录结构

```
src/components/
├── ppt/            # PPT生成相关组件
├── ui/             # shadcn/ui UI组件库
├── app-navbar.tsx  # 顶部导航栏
└── app-sidebar.tsx # 侧边栏导航
```

## 文件清单
| 文件名 | 地位 | 功能 |
|--------|------|------|
| app-navbar.tsx | 布局 | 顶部导航栏 |
| app-sidebar.tsx | 布局 | 侧边栏导航 |
| ppt/ | 模块 | PPT生成组件目录 |
| ppt-template-upload.tsx | 功能 | PPT模板上传组件 |
| ui/ | 目录 | shadcn/ui UI组件库 |
