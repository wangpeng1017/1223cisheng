**核心代码**:
```typescript
// src/lib/services/faiExtractor.ts
export async function extractFAIFromPDF(
  pdfBuffer: Buffer
): Promise<FAIExtractResult> {
  // 保存到临时文件
  const tempPath = `/tmp/${Date.now()}.pdf`;
  await fs.writeFile(tempPath, pdfBuffer);

  // 调用Python脚本
  const { stdout } = await execAsync(
    `python3 backend/services/fai_extraction.py "${tempPath}"`
  );

  // 清理临时文件
  await fs.unlink(tempPath);

  return JSON.parse(stdout);
}
```

## 七、风险与应对

### 7.1 技术风险

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|----------|
| PptxGenJS样式能力不足 | 中 | 高 | 预先生成模板页，修改内容；或切换python-pptx |
| PDF解析准确率不达标 | 中 | 中 | 提供人工修正界面；持续优化解析算法 |
| 中文字体显示问题 | 低 | 中 | 内嵌字体或使用系统字体 |
| 性能不达标 | 低 | 低 | 添加缓存、异步处理 |

### 7.2 进度风险

| 风险 | 应对措施 |
|------|----------|
| 需求变更 | 锁定MVP范围，其他功能放到二期 |
| 开发延期 | 每周review进度，及时调整计划 |
| 资源不足 | 优先完成P0任务，P1/P2任务可延后 |
